## Built-In Data Types

| Name       | Size (bytes) | Description                 |
| ---------- | ------------ | --------------------------- |
| s8         | 1            | signed 8-bit value          |
| u8         | 1            | unsigned 8-bit value        |
| bool       | 1            | true or false value         |
| s16        | 2            | signed 16-bit value         |
| u16        | 2            | unsigned 16-bit value       |
| s32        | 4            | signed 32-bit value         |
| u32        | 4            | unsigned 32-bit value       |
| s64 (todo) | 8            | signed 64-bit value         |
| u64 (todo) | 8            | unsigned 64-bit value       |
| f32 (todo) | 4            | 32-bit floating-point value |
| f64 (todo) | 8            | 64-bit floating-point value |

## Methods for composite types

### Array

- `.iter()`
    - Returns an array containing references to each value within the original array.
